# Place Metasequoia SDK here

Download the SDK from <https://www.metaseq.net/jp/download/sdk/> and extract
it so that this directory contains:

```
sdk/
  mqsdk/
    MQPlugin.h
    MQWidget.h
    MQBasePlugin.h
    mqsdk.cpp
    ...
```

The SDK is **not redistributable**, so it is intentionally excluded from
version control (see the project `.gitignore`).
